# GlyphStash UI 设计文档

版本：0.1  
日期：2026-05-18  
状态：第一阶段 UI 布局设计稿

## 1. 设计范围

本文档只定义 GlyphStash 的 UI 信息架构、页面拆分、页面职责、基础布局和功能入口。本文档不涉及：

- 色彩、品牌视觉、插画、动效风格。
- 具体前端框架、控件库或技术实现。
- 需求文档未定义的新增功能。

UI 设计必须覆盖需求分析文档中的全部 v1 功能：系统字体查看与预览、用户级安装/卸载、会话临时启用/关闭、标签与集合管理、字形浏览、指定范围字形合并、官方 API 字体搜索下载、授权提示、本地数据与诊断相关入口。

## 2. 总体信息架构

GlyphStash 使用桌面应用常见的“左侧主导航 + 中央工作区 + 右侧详情/属性区”结构。用户的大多数任务围绕字体资产浏览、筛选、详情查看和批量操作展开，因此首屏应直接进入字体库，而不是欢迎页或营销页。

### 2.1 一级页面

| 页面 | 职责 |
| --- | --- |
| 字体库 | 查看系统与本地管理字体，搜索筛选，预览字体，安装/卸载，临时启用/关闭，收藏，添加标签和集合 |
| 集合 | 管理项目字体集合，查看集合内字体，批量临时启用/关闭，导出集合清单 |
| 在线字体 | 搜索官方字体源，查看远程字体详情、授权和样式，下载字体并加入本地管理 |
| 合并工具 | 通过向导完成两个字体的指定范围字形合并、冲突预览、授权确认和导出报告 |
| 设置 | 管理目录、缓存、官方字体源配置、授权提示偏好、诊断日志 |

### 2.2 全局区域

| 区域 | 内容 |
| --- | --- |
| 左侧主导航 | 一级页面入口、当前页面状态、导航折叠入口 |
| 顶部任务栏 | 当前页面标题、当前页面主操作、全局扫描状态或任务状态入口 |
| 中央工作区 | 当前页面的主要列表、表格、网格或向导内容 |
| 右侧详情区 | 当前选中字体、集合、远程字体或合并任务的详细信息和操作 |
| 底部状态区 | 最近操作、后台任务进度、错误摘要；只显示与当前任务相关的信息 |

### 2.3 基础桌面布局

宽屏默认布局：

```text
+----------------+--------------------------------------+----------------------+
| 主导航         | 顶部任务栏                           | 详情区标题/操作      |
|                +--------------------------------------+----------------------+
| 字体库         |                                      |                      |
| 集合           | 中央工作区                           | 右侧详情区           |
| 在线字体       |                                      |                      |
| 合并工具       |                                      |                      |
| 设置           |                                      |                      |
|                +--------------------------------------+----------------------+
|                | 底部状态区                           |                      |
+----------------+--------------------------------------+----------------------+
```

中等宽度布局：

- 左侧主导航保留，但可折叠为窄导航。
- 右侧详情区不固定常驻，改为从列表项进入详情页面或覆盖式详情面板。
- 中央工作区优先保证列表、筛选和主要操作可用。

窄窗口布局：

- 主导航折叠为顶部或侧边抽屉入口。
- 页面一次只显示一个主任务区域。
- 字体详情、远程字体详情和合并报告以独立页面呈现。

## 3. 页面与功能拆分

## 3.1 字体库

字体库是默认首页，负责本地字体的浏览、预览、筛选和单字体管理。

### 页面职责

- 查看当前用户可用字体。
- 展示字体族、样式数量、来源、标签、收藏状态、激活状态。
- 支持关键字搜索、标签筛选、集合筛选、来源筛选、收藏筛选。
- 支持自定义预览文本、字号调整、预览模式切换。
- 支持重新扫描字体。
- 支持导入本地字体文件并进行用户级安装。
- 支持卸载 GlyphStash 管理的用户级字体。
- 支持单字体临时启用/关闭。
- 支持收藏、添加标签、加入集合。
- 进入字体详情和字形浏览。

### 基础布局

```text
+--------------------------------------------------------------------------------+
| 字体库                               [重新扫描] [导入字体]                      |
+--------------------------+-----------------------------------------------------+
| 筛选区                   | 字体列表                                             |
| - 搜索框                 | +-------------------------------------------------+ |
| - 来源                   | | 字体族名称                    状态/来源/收藏   | |
| - 标签                   | | 预览文本                                          | |
| - 集合                   | | 样式数量、标签、激活状态                          | |
| - 收藏                   | +-------------------------------------------------+ |
| - 激活状态               | | ...                                             | |
|                          | +-------------------------------------------------+ |
+--------------------------+-----------------------------------------------------+
| 预览设置：预览文本、字号、预览模式                                               |
+--------------------------------------------------------------------------------+
```

宽屏时，字体库右侧显示选中字体的详情区：

```text
+-----------------------------------------------------+--------------------------+
| 字体列表                                             | 字体详情                 |
|                                                     | - 基础信息               |
|                                                     | - 预览                   |
|                                                     | - 管理操作               |
|                                                     | - 标签/集合              |
|                                                     | - 授权信息               |
+-----------------------------------------------------+--------------------------+
```

### 列表项内容

每个字体列表项显示：

- 字体族名称。
- 样式数量。
- 来源：系统字体、用户级字体、GlyphStash 管理字体、临时字体。
- 激活状态：已安装、已临时启用、未启用。
- 收藏状态。
- 已绑定标签摘要。
- 使用当前预览文本渲染的字体预览。

### 操作入口

| 操作 | 入口 |
| --- | --- |
| 重新扫描 | 字体库顶部任务栏 |
| 导入字体 | 字体库顶部任务栏 |
| 搜索筛选 | 左侧筛选区 |
| 修改预览文本 | 字体库底部或列表上方预览设置区 |
| 调整字号 | 预览设置区 |
| 切换预览模式 | 预览设置区 |
| 收藏/取消收藏 | 列表项或详情区 |
| 添加标签 | 详情区 |
| 加入集合 | 详情区 |
| 用户级安装 | 详情区或导入流程 |
| 卸载字体 | 详情区，仅对允许卸载的管理字体显示 |
| 临时启用/关闭 | 列表项快捷操作和详情区 |
| 查看字形 | 详情区的字形入口 |

### 空状态与异常状态

- 首次无索引：显示“扫描字体”的主操作。
- 搜索无结果：保留筛选条件并显示清空筛选入口。
- 扫描失败：显示失败原因和重试入口。
- 字体文件损坏或格式不支持：在导入结果中逐项展示。

## 3.2 字体详情

字体详情可以作为右侧详情区，也可以在窄窗口中作为独立页面。它负责承载单个字体族或字体样式的详细查看和管理。

### 页面职责

- 展示字体基础信息。
- 展示字体预览。
- 展示样式列表。
- 展示授权信息。
- 进入完整字形浏览。
- 管理收藏、标签、集合、安装、卸载、临时启用。

### 基础布局

```text
+--------------------------------------------------+
| 字体名称                         [收藏] [更多]    |
| 来源、样式数量、激活状态                          |
+--------------------------------------------------+
| 操作区                                            |
| [临时启用/关闭] [安装] [卸载] [加入集合] [标签]   |
+--------------------------------------------------+
| 预览区                                            |
| 预览文本输入                                      |
| 字号调整                                          |
| 当前字体预览                                      |
+--------------------------------------------------+
| 样式列表                                          |
| Regular / Italic / Bold / ...                     |
+--------------------------------------------------+
| 信息区                                            |
| 基础信息 | 授权信息 | 文件信息 | 字形入口          |
+--------------------------------------------------+
```

### 信息区内容

| 分区 | 内容 |
| --- | --- |
| 基础信息 | family、subfamily、full name、PostScript name、版本、制造商、格式 |
| 授权信息 | license 名称、license 来源、未知授权标记、来源链接 |
| 文件信息 | 文件路径、文件格式、hash、管理状态、安装状态 |
| 字形入口 | 字符覆盖摘要、进入字形浏览 |

### 显示规则

- 系统字体不显示直接卸载按钮；如必须显示相关状态，只显示“系统字体，不支持在 v1 中卸载”。
- 未知授权必须在授权信息区明确标记。
- 临时启用状态与永久安装状态分开显示。
- 如果某操作不可用，说明原因应靠近操作入口显示。

## 3.3 字形浏览

字形浏览用于查看字体中的 Unicode 映射字符和单个 glyph 信息。

### 页面职责

- 展示字体包含的 Unicode 映射字符。
- 支持按 Unicode 区块筛选。
- 支持搜索字符、Unicode 码位或输入文本。
- 展示单个字形信息：字符、Unicode、glyph name、glyph id、所属字体样式。
- 支持复制字符和复制 Unicode 码位。
- 为无 Unicode 映射 glyph 预留“未映射字形”区域。
- 对缺字搜索给出明确反馈。

### 基础布局

```text
+--------------------------------------------------------------------------------+
| 字形浏览：字体名称                                      [返回字体详情]          |
+--------------------------+-----------------------------------------------------+
| 筛选区                   | 字形网格                                             |
| - 搜索字符/Unicode       | +-----+ +-----+ +-----+ +-----+ +-----+             |
| - Unicode 区块           | | 字  | | A   | | 1   | | ?   | | ... |             |
| - 映射状态               | |U+...| |U+...| |U+...| |U+...| |     |             |
|                          | +-----+ +-----+ +-----+ +-----+ +-----+             |
+--------------------------+-----------------------------------------------------+
| 选中字形详情                                                                   |
| 字符、Unicode、glyph name、glyph id、所属样式、[复制字符] [复制 Unicode]        |
+--------------------------------------------------------------------------------+
```

### 网格行为

- 字形网格必须分页、分段或虚拟滚动，避免大型 CJK 字体一次性渲染全部字形。
- 字形单元固定尺寸，避免字符大小不同导致布局跳动。
- 搜索不到字符时，显示“当前字体不包含该字符/码位”。

## 3.4 集合

集合页负责项目字体包管理，以及集合级批量启用和关闭。

### 页面职责

- 创建、重命名、删除集合。
- 搜索集合。
- 查看集合内字体。
- 从集合中移除字体。
- 集合批量临时启用。
- 集合批量关闭临时启用。
- 导出集合清单。
- 查看集合内字体的安装、临时启用、授权摘要。

### 基础布局

```text
+--------------------------------------------------------------------------------+
| 集合                                      [新建集合]                            |
+--------------------------+-----------------------------------------------------+
| 集合列表                 | 集合详情                                             |
| - 搜索集合               | 集合名称                         [重命名] [删除]   |
| - 集合 A                 | 字体数量、已临时启用数量、未知授权数量              |
| - 集合 B                 | [临时启用全部] [关闭全部] [导出清单]                |
| - 集合 C                 |                                                     |
|                          | 集合内字体列表                                       |
|                          | 字体名称、样式、状态、授权、[移除]                  |
+--------------------------+-----------------------------------------------------+
```

### 删除规则

- 删除集合只删除集合与字体的关系，不删除字体文件。
- 集合内移除字体只移除关系，不卸载字体。
- 批量关闭只关闭由当前会话临时启用的字体，不执行卸载。

## 3.5 标签管理

标签不作为一级页面，作为字体库和字体详情中的管理入口出现。这样可以减少导航层级，同时满足标签管理需求。

### 页面职责

- 创建标签。
- 重命名标签。
- 删除标签。
- 搜索标签。
- 给字体添加或移除标签。
- 在字体库中按标签筛选。

### 基础布局

标签管理以弹出面板或侧边面板呈现：

```text
+--------------------------------------+
| 标签                                  |
| 搜索标签                              |
+--------------------------------------+
| 已选标签                              |
| [衬线] [中文] [项目A]                 |
+--------------------------------------+
| 全部标签                              |
| 标签名称                 [重命名][删除]|
| 标签名称                 [重命名][删除]|
+--------------------------------------+
| [新建标签]                            |
+--------------------------------------+
```

### 显示规则

- 删除标签只移除标签和字体的关联，不删除字体。
- 字体详情中只显示当前字体相关标签和“管理标签”入口。
- 字体库筛选区显示标签列表或标签搜索入口。

## 3.6 在线字体

在线字体页负责官方字体源搜索、远程字体详情展示和下载。

### 页面职责

- 搜索官方字体源中的字体。
- 展示字体族、样式、分类、支持子集、更新时间、license 信息、来源链接。
- 下载指定字体样式到 GlyphStash 管理目录。
- 下载后加入标签、集合、收藏。
- 下载后选择用户级安装或临时启用。
- 显示 API key 缺失、网络失败、限流等状态。

### 基础布局

```text
+--------------------------------------------------------------------------------+
| 在线字体                                                   字体源：Google Fonts |
+--------------------------------------------------------------------------------+
| 搜索框                                           [搜索]                         |
+--------------------------------------+-----------------------------------------+
| 搜索结果                             | 远程字体详情                            |
| 字体族名称                           | 字体族名称                              |
| 分类、样式数量、更新时间             | 分类、支持子集、更新时间                |
| license 摘要                         | license 信息、来源链接                  |
|                                      | 样式列表                                |
|                                      | [下载所选样式]                          |
|                                      | 下载后操作：加入集合、添加标签、收藏、  |
|                                      | 用户级安装、临时启用                    |
+--------------------------------------+-----------------------------------------+
```

### 显示规则

- v1 只显示官方 API 已接入的字体源，不显示未实现的第三方站点入口。
- “下载”不表达“可商用”，license 信息必须与下载操作同屏可见。
- 如果 API key 未配置，显示配置入口；配置入口跳转到设置页对应区域。
- 下载完成后展示本地管理状态和后续操作，不自动隐藏授权信息。

## 3.7 合并工具

合并工具以向导方式呈现，确保用户按顺序完成选择、范围、冲突、授权和导出。

### 页面职责

- 选择基础字体 A。
- 选择补充字体 B。
- 输入 Unicode 范围或选择 Unicode 区块。
- 预览重复码位、字体单位不匹配、缺失字形、license 未确认、格式不支持等问题。
- 显示默认冲突策略：基础字体已有码位默认跳过。
- 要求用户确认授权风险。
- 设置输出文件路径和输出字体名称。
- 执行合并并展示报告。

### 基础布局

```text
+--------------------------------------------------------------------------------+
| 合并工具                                                                       |
+--------------------------------------------------------------------------------+
| 步骤：1 选择字体 > 2 指定范围 > 3 预览冲突 > 4 授权与导出 > 5 报告             |
+--------------------------------------------------------------------------------+
| 当前步骤内容                                                                   |
|                                                                                |
| [上一步]                                                     [下一步/开始导出] |
+--------------------------------------------------------------------------------+
```

### 步骤布局

#### 步骤 1：选择字体

```text
+--------------------------------------+-----------------------------------------+
| 基础字体 A                            | 补充字体 B                              |
| 搜索本地字体                          | 搜索本地字体                            |
| 字体列表                              | 字体列表                                |
| 已选字体摘要                          | 已选字体摘要                            |
+--------------------------------------+-----------------------------------------+
```

#### 步骤 2：指定范围

```text
+--------------------------------------------------------------------------------+
| Unicode 范围输入：U+4E00-U+9FFF                                                 |
| 或选择 Unicode 区块                                                             |
| 范围摘要：预计检查字形数量、补充字体覆盖数量                                     |
+--------------------------------------------------------------------------------+
```

#### 步骤 3：预览冲突

```text
+--------------------------------------------------------------------------------+
| 冲突摘要                                                                       |
| - 重复码位                                                                     |
| - 缺失字形                                                                     |
| - 字体单位不匹配                                                               |
| - 格式不支持                                                                   |
| - 授权未知                                                                     |
+--------------------------------------------------------------------------------+
| 冲突明细列表                                                                   |
| 码位、字符、基础字体状态、补充字体状态、默认处理结果                            |
+--------------------------------------------------------------------------------+
```

#### 步骤 4：授权与导出

```text
+--------------------------------------------------------------------------------+
| 授权确认                                                                       |
| 基础字体 license 状态                                                           |
| 补充字体 license 状态                                                           |
| 用户确认：我确认有权执行合并和导出                                               |
+--------------------------------------------------------------------------------+
| 输出设置                                                                       |
| 输出文件路径                                                                    |
| 输出字体名称                                                                    |
| [开始导出]                                                                      |
+--------------------------------------------------------------------------------+
```

#### 步骤 5：报告

```text
+--------------------------------------------------------------------------------+
| 合并结果：成功/失败                                                             |
| 输出文件路径                                                                    |
| 输入字体、范围、跳过数量、合并数量、冲突数量、license 确认时间                  |
| 错误详情或诊断日志入口                                                          |
+--------------------------------------------------------------------------------+
```

### 显示规则

- 未完成授权确认时，不能开始导出。
- 输出不能覆盖原始字体文件。
- 合并失败时保留报告区域，显示可理解错误和诊断入口。
- 默认冲突策略必须在冲突预览中可见。

## 3.8 设置

设置页只包含需求文档中已经定义的配置和诊断入口。

### 页面职责

- 管理 GlyphStash 本地管理目录。
- 管理缓存。
- 配置 Google Fonts API key。
- 管理授权提示偏好。
- 查看诊断日志。

### 基础布局

```text
+--------------------------------------------------------------------------------+
| 设置                                                                           |
+--------------------------------------------------------------------------------+
| 本地管理目录                                                                   |
| 当前目录、选择目录、目录可用性状态                                               |
+--------------------------------------------------------------------------------+
| 缓存                                                                           |
| 字体索引缓存、预览缓存、清理缓存入口                                             |
+--------------------------------------------------------------------------------+
| 在线字体源                                                                     |
| Google Fonts API key、配置状态                                                  |
+--------------------------------------------------------------------------------+
| 授权提示                                                                       |
| 合并/导出前提示策略                                                             |
+--------------------------------------------------------------------------------+
| 诊断日志                                                                       |
| 最近操作、扫描错误、下载错误、合并错误                                           |
+--------------------------------------------------------------------------------+
```

### 显示规则

- 不显示未实现字体源配置。
- 不显示系统级字体管理开关。
- 不显示 macOS/Linux 专属设置。
- 诊断日志只用于排查和追踪需求中定义的操作，不作为扩展功能入口。

## 3.9 导入字体流程

导入字体是字体库中的任务流程，不作为一级页面。

### 流程职责

- 选择本地字体文件。
- 显示文件解析结果。
- 检测重复字体、同名不同版本、格式不支持、文件损坏。
- 选择导入后的处理：加入 GlyphStash 管理、用户级安装、临时启用、加入集合、添加标签。
- 展示导入结果。

### 基础布局

```text
+--------------------------------------------------------------------------------+
| 导入字体                                                                       |
+--------------------------------------------------------------------------------+
| 已选择文件列表                                                                 |
| 文件名、格式、解析状态、重复状态、授权状态                                       |
+--------------------------------------------------------------------------------+
| 导入后操作                                                                     |
| 加入管理目录、用户级安装、临时启用、加入集合、添加标签                           |
+--------------------------------------------------------------------------------+
| [取消]                                                               [开始导入] |
+--------------------------------------------------------------------------------+
```

### 显示规则

- 文件损坏或格式不支持的项目不能继续导入。
- 同名不同版本必须展示差异提示。
- 授权未知不阻止导入，但需要在状态中标记。

## 3.10 确认与提示 UI

以下确认与提示属于需求内的安全边界，必须设计入口和展示方式。

| 场景 | UI 形式 | 必需内容 |
| --- | --- | --- |
| 卸载字体 | 确认弹窗 | 字体名称、影响范围、是否为 GlyphStash 管理字体 |
| 尝试卸载系统字体 | 阻止提示或强提示 | 说明 v1 不支持系统字体卸载 |
| 临时启用可见性限制 | 信息提示 | 说明可能只保证 GlyphStash 内部预览可用，外部应用可见性取决于系统行为 |
| 授权未知 | 标签或提示条 | license 未知，不代表可商用 |
| 合并导出授权确认 | 必须确认弹窗或向导步骤 | 输入字体、license 状态、用户确认项 |
| 下载失败 | 错误提示 | 网络/API/权限/文件错误原因和重试入口 |
| 合并失败 | 报告页错误区 | 失败原因、诊断日志入口 |
| 扫描失败 | 页面内错误区 | 失败原因和重试入口 |

## 4. 全局交互规则

### 4.1 操作分级

- 主操作放在页面顶部任务栏或向导底部，例如导入字体、重新扫描、开始导出。
- 单字体操作放在字体详情区，例如安装、卸载、临时启用、收藏、标签、集合。
- 批量操作放在集合详情页，例如临时启用全部、关闭全部、导出清单。
- 风险操作必须确认，例如卸载、合并导出。

### 4.2 状态表达

字体状态必须区分：

- 系统字体。
- 用户级安装字体。
- GlyphStash 管理字体。
- 临时启用字体。
- 未启用但已下载字体。
- 授权未知字体。

状态显示应靠近字体名称或操作区，避免用户误把临时启用理解为永久安装。

### 4.3 列表与详情关系

- 字体库、集合、在线字体都采用“列表 + 详情”的主关系。
- 用户选择列表项后，右侧或下一层页面显示详情。
- 删除、卸载、导出等风险操作不直接在列表中完成，必须进入确认流程。

### 4.4 搜索与筛选

- 字体库搜索作用于本地字体索引。
- 集合搜索作用于集合名称。
- 在线字体搜索作用于官方字体源。
- 字形浏览搜索作用于当前字体的字符、Unicode 或输入文本。
- 各页面筛选条件只影响当前页面，不做跨页面隐藏状态。

## 6. 明确不显示的 UI

为避免 UI 超出需求，v1 不设计以下入口：

- 系统级字体安装/卸载开关。
- macOS 或 Linux 专属页面。
- 未实现的第三方字体站点搜索入口。
- 字体轮廓编辑、字距编辑、OpenType feature 编辑入口。
- 自动判断商业授权的按钮或结论。
- 字体评分、AI 推荐、字体配对等需求外能力。
- 色彩主题、皮肤、视觉外观定制入口。

## 7. UI 验收标准

- 一级页面能覆盖需求文档中全部 v1 功能。
- 字体库作为默认首页，用户打开应用即可浏览和预览字体。
- 每个风险操作都有明确确认或阻止提示。
- 临时启用、永久安装、系统字体、管理字体的状态在 UI 中不会混淆。
- 字形浏览、在线字体、合并工具都有独立清晰的任务路径。
- 页面布局只表达功能和层级，不依赖颜色来区分关键状态。
- UI 不显示需求外功能入口。
