# GlyphStash

English | [简体中文](README.zh-CN.md)

GlyphStash is a Windows desktop tool for managing font files and keeping a local font library organized.

It helps you:

- Import local font files into a managed library.
- Browse, search, tag, and group fonts into collections.
- Temporarily activate fonts for the current session or install them for the current Windows user.
- Search and download fonts from Google Fonts with your own API key.
- Preview coverage and merge fonts with conflict reporting.
- Update the app from GitHub Releases.

GlyphStash stores user data locally under `%LocalAppData%\GlyphStash`.
