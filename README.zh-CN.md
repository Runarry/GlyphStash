# GlyphStash

[English](README.md) | 简体中文

GlyphStash 是一个 Windows 桌面字体管理工具，用来整理本地字体文件并维护自己的字体库。

它可以帮助你：

- 将本地字体文件导入到托管字体库。
- 浏览、搜索字体，并用标签和集合进行整理。
- 临时启用字体，或安装到当前 Windows 用户。
- 使用自己的 Google Fonts API key 搜索和下载在线字体。
- 预览字符覆盖范围，并在合并字体时报告冲突。
- 通过 GitHub Releases 更新应用。

GlyphStash 的用户数据保存在本机 `%LocalAppData%\GlyphStash`。
